集运平台

一端连接海外需求，一端整合国内供应链 —— 用「集运 + 分销」打通跨境履约全链路

9态跟踪
国内作业（效率核心）

预报入库 → 拆袋理货（PDA 扫单校验）→ 上架 → 在库。全程拍照称重留证。

集运增值（利润核心）

合箱、分装、加固、保价。增值服务毛利率 40%–70%，比运费差价更厚。

国际履约（体验核心）

干线运输 → 清关 → 派送，9 态全程轨迹可视，确定性即口碑。

Revenue & Strategic Value · 收入结构 + 战略价值

钱从哪里来 — 给集团带来什么价值

客户先付费后履约，预充值形成无息资金池。集运不仅是独立业务，更是集团能力外溢与生态协同的战略支点。

收入结构（典型占比）
国际运费差价60–70% 收入 · 毛利 10–25%
仓储 / 操作 / 挂号8–15% 收入 · 毛利 40–70%
分销佣金视分销占比
关税代缴汇差2–5% 收入
保险 / 增值 / 其他1–3% 收入
资金飞轮：预收运费消除账期 → 预充值沉淀无息资金 → 规模拿价压低干线成本 → 汇差与增值增厚利润 → 利润反哺获客。
给集团带来的多维度战略价值
🏭
仓库操作能力外溢 — 对外做电商操作仓服务

标准化作业能力产品化，承接整进散出电商操作仓服务，形成新收入来源和行业影响力。

👥
面向直客群体 — 扩大公司客户类型

直接触达 C 端海外终端消费者，打破原有 B 端结构，增加客户多样性与抗风险能力。

🏷
商品分销前期准备 — 为海外用户分销铺路

积累的客户信任、物流网络与支付通道，为后续优质商品分销做好前期准备。

🔗
ABW 项目协同 — 独立经营构建 + 更好集运到 ABW

为 ABW 做好独立经营架构，提供更好集运服务，资源复用与流量互导，1+1>2 协同效应。

💻
技术铺垫 — 为重构仓库操作系统（速递管家）打底

集运 WMS 中台沉淀的仓储作业、库位、PDA 数字化能力，可为公司重构仓库操作系统（速递管家）做技术铺垫，减少后续工作量。

💰
低成本起步 — 资源基建已具备

仓库、IT 系统、运力渠道、清关能力均已就绪，属于低风险、高杠杆增量业务。

战略总结：集运项目是集团在跨境赛道上的战略支点——既是能快速验证并产生正向现金流的独立业务，又是仓储外溢、客户结构优化、ABW 协同与分销布局的前哨阵地。投入小、见效快、协同大。
